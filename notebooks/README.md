# Notebooks

Four walkthroughs against the pipeline outputs, each with its charts rendered. Run them in order after `make panel` (and `make stability` before notebook 09).

- [01_data_coverage.ipynb](01_data_coverage.ipynb): coverage audit of every series and the source choices it forced
- [08_understanding.ipynb](08_understanding.ipynb): an end-to-end tour of the pipeline, run after `make panel`
- [09_spectral_radius_robustness.ipynb](09_spectral_radius_robustness.ipynb): the VAR-stability screen behind `make stability`
- [10_euro_fx_duplication.ipynb](10_euro_fx_duplication.ipynb): the euro-area redundancy check for the FX panel
